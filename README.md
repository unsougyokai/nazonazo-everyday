# 毎日なぞなぞ

ピンク色の眼鏡をかけた2足歩行のぞう、**なぞなぞうさん**が  
毎日1問、あなたに「なぞなぞ」をお届けするウェブサイトです。

---

## 🐘 なぞなぞうさんとは？

- ぞうをモチーフにしたマスコットキャラクター  
- ピンク色の身体  
- 眼鏡をかけている  
- 2足歩行で歩く、ちょっと知的でかわいいキャラ  

毎日、なぞなぞうさんがあなたに1問だけ問題を出します。  
答えを見るボタンを押すと、そっと答えを教えてくれます。

---

## 🌐 サイトURL

**https://unsougyokai.github.io/nazonazo-everyday/**

世界中どこからでもアクセスできます。

---

## 📅 仕組み

- HTML / CSS / JavaScript のみで構成されたシンプルなサイト  
- 日付（1〜31）を使って、毎日違うなぞなぞを表示  
- GitHub Pages を利用して無料で公開
